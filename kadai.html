課題3：企業のコーポレートサイトを作る
株式会社ネクストブリッジ

実務でよくある「コーポレートサイトのTOPページ」を再現します。固定ヘッダー、自動再生スライダー、数字のカウントアップ、タブによる絞り込み、スクロール連動のフェードイン、フォームの入力チェックなど、JavaScriptの機能を8つ実装します。これができれば、実案件のコーディングを任せられるレベルです。

使う技術HTML / CSS / JavaScript（本格的に）
JavaScript8機能（スライダー・IntersectionObserver・バリデーション等）
目安時間10〜14時間

課題のねらい

  • 固定ヘッダー（position: fixed）と、その分のページ上部の余白・ページ内リンクのずれ対策ができる
  • スライドを重ねて opacity で切り替えるフェード式スライダーを、setInterval で自動再生できる
  • IntersectionObserver で「画面に入ったら○○する」を実装できる（フェードイン・カウントアップ）
  • data属性を使って、タブによる絞り込みや、フォームのチェック内容をHTMLから読み取れる
  • フォームの入力チェック（バリデーション）を、エラー表示・再チェック・送信完了まで含めて実装できる
  • これまでの課題より要素数が多いページを、崩れずに・破綻しないCSS設計で仕上げられる
この課題の心構え

機能が多いので、一度に全部やろうとせず「1機能ずつ動くところまで作って確認」を繰り返してください。JavaScriptは console.log() で値を確認しながら進めるのがコツです。仕様書は長いですが、実務のデザインカンプ＋指示書も同じくらいの情報量です。

観察ポイント
  • ページを読み込んで5秒待つとスライドが切り替わる。矢印・ドットでも切り替わる
  • スクロールするとヘッダーに影が付き、各セクションがふわっと下から現れる
  • 「数字で見る」が画面に入ると数字が増えていく
  • 実績のタブをクリックすると絞り込まれる
  • フォームを空のまま送信するとエラーが出る。正しく入力して送信すると完了メッセージに切り替わる
  • スマホ幅では、ハンバーガーメニューがヘッダーの下から全画面でフェードインする（課題2のドロワー型とは違う）

トップへ戻る・フェードイン

トップへ戻る課題2と同じ仕様（色はネイビー）
フェードインセクション見出し・リード文・各カード・テーブル・フォームなどに fade-in クラスを付け、初期状態は「透明・24px下にずれた」状態。画面に入ったら 0.8秒でふわっと元の位置に現れる。一度表示したら戻らない

JavaScript要件8つの機能をすべて実装してください

機能1：ヘッダーの影

スクロール量が 50px を超えたらヘッダーに is-scrolled クラスを付け、50px以下なら外す。

機能2：ハンバーガーメニュー

課題2と同じ。クラスの付け外しで開閉。リンククリックで閉じる。aria-expanded も切り替える。

機能3：スライダー

  • showSlide(番号) のような「指定した番号のスライドを表示する関数」を1つ作り、スライドとドットの is-active を付け替える
  • 5秒ごとに次のスライドへ自動で進む（setInterval）。最後の次は最初に戻る
  • 「›」で次へ、「‹」で前へ（最初の前は最後へ）。ドットをクリックするとそのスライドへ
  • 矢印・ドットを操作したら、自動再生のタイマーをリセットする（操作直後にすぐ切り替わらないように）

機能4：スクロールで表示（フェードイン）

  • IntersectionObserver を使い、.fade-in の要素が画面に入ったら is-visible クラスを付ける
  • 画面下端から10%入ったところで発火させる（rootMargin）
  • 一度表示した要素は監視をやめる（unobserve）

機能5：数字のカウントアップ

  • .count の要素が画面に半分以上入ったら、0から data-count の値まで 1.5秒かけて増やす
  • requestAnimationFrame を使い、最初は速く・最後はゆっくり（イージング）にする
  • 終わったら必ず目標値ぴったりで止める。一度だけ実行する

機能6：実績のタブ切り替え

  • タブの data-filter と、カードの data-category を比較して、一致しないカードに is-hidden を付ける。「すべて」は全部表示
  • クリックしたタブだけ is-active にする

機能7：フォームの入力チェック

  • 送信時（submit）に preventDefault() で送信を止め、全項目をチェックする
  • チェック内容：必須項目が空 → 「この項目は必須です」／ メール形式が不正 → 「メールアドレスの形式が正しくありません」／ 電話番号に数字とハイフン以外 → 「電話番号は半角数字とハイフンで入力してください」／ 種別未選択 → 「お問い合わせ種別を選択してください」／ 同意なし → 「同意にチェックを入れてください」
  • エラーの項目に is-error クラスを付け、メッセージを表示。最初のエラー項目までスクロールする
  • エラー中の項目は、入力（input / change）のたびに再チェックし、直ったらエラーを消す
  • すべてOKならフォームを隠して完了メッセージを表示する（実際の送信は行わない）
  • 「どの項目が必須か」「どんなチェックか」は data-required / data-type="email" のようにHTML側の属性で指定し、JSはそれを読んで動く汎用的な作りにする（項目ごとにif文を書かない）
  • ブラウザ標準のチェックと二重にならないよう、form に novalidate を付ける

機能8：トップへ戻る

ヒント2：スライドを重ねる

スライダーの親に position: relative; height: 600px; overflow: hidden;、各スライドに position: absolute; inset: 0; opacity: 0; transition: opacity 1s;、表示中のスライドだけ .is-active { opacity: 1; z-index: 1; }。矢印とドットは z-index: 2 でスライドの上に置きます。

ヒント3：スライダーの「次へ」で最後の次は最初に戻す 
function showSlide(index) {
  // 例：3枚のとき  3 → 0、 -1 → 2 になる
  currentIndex = (index + slides.length) % slides.length;
  slides.forEach(function (slide, i) {
    slide.classList.toggle('is-active', i === currentIndex);
  });
  // ドットも同じように切り替える
}

自動再生は timerId = setInterval(() => showSlide(currentIndex + 1), 5000)。矢印を押したときは clearInterval(timerId) してから再度 setInterval するとタイマーがリセットされます。

ヒント5：カウントアップのイージング 
function countUp(element) {
  const target = Number(element.dataset.count);
  const duration = 1500;
  const start = performance.now();

  function update(now) {
    const progress = Math.min((now - start) / duration, 1); // 0〜1
    const eased = 1 - Math.pow(1 - progress, 3);            // 最後ゆっくり
    element.textContent = Math.floor(target * eased);
    if (progress < 1) requestAnimationFrame(update);
    else element.textContent = target;
  }
  requestAnimationFrame(update);
}

ヒント7：フォームの汎用チェック関数の考え方

「1つの項目を受け取って、エラーメッセージ（なければ空文字）を決め、表示を更新し、OKなら true を返す」関数 validateField(field) を作ります。送信時は全項目に対してこの関数を呼び、1つでも false があれば送信しません。

function validateField(field) {
  const row = field.closest('.form__row');          // 項目全体の枠
  const errorEl = row.querySelector('.form__error');
  const type = field.dataset.type || 'text';
  const required = field.hasAttribute('data-required');
  let message = '';

  if (type === 'radio') {
    if (required && !field.querySelector('input:checked')) message = '...';
  } else if (type === 'check') {
    if (required && !field.checked) message = '...';
  } else {
    const value = field.value.trim();
    if (required && value === '') message = 'この項目は必須です';
    else if (type === 'email' && value && !/^[^\s@]+@[^\s@]+\.[^\s@]+$/.test(value)) message = '...';
    else if (type === 'tel' && value && !/^[0-9\-]+$/.test(value)) message = '...';
  }

  row.classList.toggle('is-error', message !== '');
  errorEl.textContent = message;
  return message === '';
}

ラジオボタンは「グループを包む div」に data-required data-type="radio" を付けると、この1つの関数で扱えます。

ヒント8：ナビのホバーで下線が左から伸びる

リンクに position: relative;、::after で幅100%・高さ2pxの線を下端に置き、transform: scaleX(0); transform-origin: left; で隠しておきます。ホバー時に scaleX(1) にすると左から伸びます。

ヒント9：カードの「詳しく見る」を常に下端に揃えたい

カードを display: flex; flex-direction: column; にして、本文の p に flex: 1; を付けると、本文が余った高さを埋めてリンクが下端に揃います（Gridの各セルは自動で同じ高さになります）。
